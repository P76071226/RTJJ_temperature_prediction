🏗️ Pipeline Architecture

1

Market Collector

Fetches 10 binary markets from Polymarket CLI → Normalizes to 13 temperature intervals (24-36°C) → Outputs data/market_raw.json

2

OSINT Researcher

Open-Meteo forecast (mean, std, cloud%, precip, wind) + JMA METAR observations + Sea breeze flag + Time features → Outputs data/osint_features.json

3

Model Builder

Loads XGBoost + Isotonic calibration (v2) → 13 features → Predicts 13 interval probabilities → Outputs data/model_probs.json

4

Validator

Compares model vs market probs → Max abs diff > 8pp threshold → Identifies signal intervals → Logs observed temp → Outputs data/validation_log.json

5

Report Generator

Chart.js visualizations → Probability comparison charts → Feature importance → Signal cards → Saves reports/report_*.html

Feature Engineering

# 13 Features for XGBoost
features = [
    'fc_mean',        # Open-Meteo forecast mean temp
    'fc_std',         # Forecast ensemble spread
    'cloud',          # Cloud cover %
    'precip',         # Precipitation forecast (mm)
    'wind',           # Wind speed avg
    'sea_breeze',     # Sea breeze flag (0/1)
    'dow',            # Day of week (0-6)
    'sin_doy',        # Seasonal: sin(2π*DOY/365)
    'cos_doy',        # Seasonal: cos(2π*DOY/365)
    'cloud_sq',       # Non-linear: cloud²
    'cloud_x_sea',    # Interaction: cloud × sea_breeze
    'fc_x_cloud',     # Interaction: fc_mean × cloud
    'hist_err'        # Previous day forecast error
]

Model Configuration

# XGBoost Classifier
XGBClassifier(
    n_estimators=200,
    max_depth=4,
    learning_rate=0.05,
    subsample=0.8,
    colsample_bytree=0.8,
    objective='multi:softprob',
    num_class=13,

IsotonicRegression(out_of_bounds='clip')

Signal Detection Logic

# For each temperature interval:
edge = model_prob - market_prob
# Signal if edge > 8 percentage points
if edge > 0.08:
    signal = 'BUY'   # Model thinks interval more likely than market
elif edge < -0.08:
    signal = 'SELL'  # Market overpriced vs model
else:
    signal = 'HOLD'
